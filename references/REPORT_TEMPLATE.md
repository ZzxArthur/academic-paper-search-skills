# 【研究主题】科研文献调研与创新能力图谱

> **模板使用规则**：本文件只定义报告结构，不是现成检索结果。所有 `【待填】` 与方括号须在真实检索后替换；未核实字段写「未核实」，没有代码写明状态而不伪造链接。论文数量、能力列和段落长度应按实际需求调整，不能为了填满模板虚构内容。
>
> **宽泛主题**：先在对话中询问「需要最新综述与代表性文献，还是聚焦细分方向？」；在用户选择前不要填写本报告。选综述时将综述排在合适的阅读位置，并计入 N 篇。

**一句话总览**：【该研究问题是什么、当前主流方法的主要分歧在哪里】。

## 1. 推荐阅读路径：从基础到近期前沿

> 阅读次序**不必等于出版年份排序**。对每个阶段说明需要掌握的先修知识，以及它怎样支撑下一阶段。

| 阶段 | 建议阅读顺序（简称） | 本阶段核心问题 | 为什么先读这一组 |
|---|---|---|---|
| 第一阶段：综述/奠基 | 【1、2】 | 【任务定义、基础模型、评价协议】 | 【先修原因】 |
| 第二阶段：关键演进/分支 | 【3、4、5】 | 【研究范式如何分化、关键瓶颈如何缓解】 | 【承接第一阶段的关系】 |

*阶段分配按实际 N 与论文学术关系增删，不强制每阶段固定篇数。*

## 3. 逐篇精读卡片（每篇一节，顺序与总表一致）

### ①【奠基篇 / 关键演进篇 / 近期代表篇】【论文简称】完整英文标题

- **收录信息**：首次公开【日期】；官方录用【状态/日期】；正式出版【日期/年份】；会议/期刊【真实名称或仅预印本】。
- **论文原文**：【URL】；**官方 GitHub**：【✓/△/✗/? + URL 或状态说明】；**发表证明**：【会议/出版社/论文集等 URL】。
- **研究问题**：【论文解决什么明确问题；此前方案的瓶颈是什么】。
- **方法概述**：【输入 → 核心表示/算法/训练机制 → 输出；可用 2–3 句】。
- **核心创新点**：【相较什么先前工作，具体新增什么，而非泛泛称性能更好】。
- **关键实验依据**：【数据集/任务、主要对照、可核实的实验结论；标出章节/表格或出处】。
- **局限与适用边界**：【作者明确报告的限制或基于证据的审慎分析】。
- **阅读定位**：【为什么第 ① 篇读；其知识点如何衔接下一篇】。
- **证据深度**：【全文级 / 摘要级 / 待核实】。

> 对第 ②～N 篇重复同样结构。快速入门模式可压缩方法、创新、实验和阅读定位为 3–5 句话；深入研究模式则补充架构图说明、关键公式、训练细节、消融、复现成本及失败模式。

## 4. 核心创新点与技术能力矩阵

**横坐标**：按本主题挑选 **6–10 个**能区分论文的核心机制、创新能力或验证特征；**纵坐标**：第 2 节的论文简称，顺序保持一致。

**符号定义**：`✓` 明确实现并有证据；`✗` 本论文未报告/未采用/未验证；`△` 部分实现或条件受限；`?` 证据不足。`✗` 不是「整个领域无人做过」。

### 4.3 判定依据与横向差异

- **关键单元格依据**：【论文简称 × 维度】→【为何标 ✓/✗/△/?；方法节/实验表/附录/官方代码 URL】。
- **差异一：研究目标或问题定义**：【哪类方法针对什么约束】。
